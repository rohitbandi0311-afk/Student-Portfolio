# Projects

The following descriptions are written for a student portfolio. Adjust the contribution and technology details to match the exact work you personally completed.

## Project 1: University Management System
- **Problem:** Student and academic information can become difficult to organise when records are handled separately.
- **Solution:** A database-backed university management application concept for storing and viewing student information.
- **Technologies:** Python, Flask, MySQL.
- **My contribution:** Worked on the project structure and the student-record management workflow.
- **What I learned:** How a web application can connect its interface and server-side logic to a relational database.
- **Possible improvement:** Add authentication, role-based access, input validation, and reports.

## Project 2: Loan Prediction System
- **Problem:** Reviewing applicant information manually can be time-consuming and may be inconsistent.
- **Solution:** A machine-learning project concept that uses applicant attributes to estimate a loan approval outcome.
- **Technologies:** Python and machine-learning/data-analysis libraries, depending on the implementation.
- **My contribution:** Worked on developing the project concept and exploring how applicant data can be analysed.
- **What I learned:** The importance of preparing data and evaluating model predictions carefully.
- **Possible improvement:** Add a documented dataset, model evaluation metrics, explainability, and fairness checks.

## Project 3: RAILOPT AI
- **Problem:** Railway block planning and asset availability involve operational constraints that can be difficult to coordinate.
- **Solution:** An AI-assisted prototype concept to support planning and improve visibility into rail-block and asset availability.
- **Technologies:** AI-assisted prototyping and web application tools used in the implementation.
- **My contribution:** Worked on the prototype and project concept.
- **What I learned:** How to translate an operational problem into a demonstrable software prototype.
- **Possible improvement:** Validate the prototype with realistic data, clear constraints, and measurable planning outcomes.
