# Bandi Rohith — Student Portfolio

A student portfolio website for presenting academic interests, technical skills, and project work. This project is also used to practise the Git and GitHub workflows required for the practical assessment.

## Project contents
- `index.html` — main portfolio webpage
- `style.css` — responsive page styling
- `about.md` — introduction and career objective
- `skills.md` — technical skills and learning goals
- `projects.md` — project descriptions
- `education.md` — education and achievements
- `contact.md` — professional profile links
- `contributions/` — Git/GitHub learning notes
- `.gitignore` — files Git should ignore

## View the website
Open `index.html` in a web browser. No backend or installation is required.

## Git & GitHub practical assessment
1. Inspect and customise the portfolio.
2. Initialise Git and make the first commit.
3. Create a GitHub repository named `Student-Portfolio` and push the `main` branch.
4. Create an `add-projects` branch, update `projects.md`, and push it.
5. Open a pull request from `add-projects` into `main` and merge if permitted.
6. Create an `add-certifications` branch, update `skills.md` and `education.md`, then push and open a pull request.
7. Fork the trainer's repository, create an `improve-documentation` branch, and add a contribution file named with your roll number.

## Important
This ZIP intentionally excludes the `.git` directory so you can start Task 2 with a fresh local repository. Replace any remaining study-period or roll-number placeholders with your own accurate details. Do not publish passwords, access tokens, API keys, home addresses, or other sensitive information.
